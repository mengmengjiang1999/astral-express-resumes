# 星穹列车在线编辑器

选择开拓者简历或漫展扩列条，在网页中修改资料、切换深浅配色、上传头像或二维码，预览并下载 PDF / PNG。

- 简历保持单页 A4。内容超过一页会提示精简，禁止导出截断的简历。
- 扩列条宽 80 mm，高度随内容伸缩。About me 在头像左侧，不重复提示填写 CN，头像下方可填写游戏 UID。尾部固定为“愿此行，终抵群星！”，没有编辑入口，导入旧资料也不会覆盖。示例仅保留标准版和简短版，标准版仍可自由增加内容。下方依次为「坑 / 我推 / NG / 其他 / 联系方式」，空栏目自动隐藏并连续编号；CP 内容按需写在我推、NG 或其他中，也可以完全不写。
- 联系方式可自由添加 QQ、微信、小红书、B站或自定义平台，最多 12 项。每项独立填写平台、账号、备注、上传二维码，支持删除及上移/下移；关闭二维码区域即可只留文字。图片跟随对应组件，不受排序影响。
- 预览与 PDF 由同一次 Typst 排版生成；PNG 从同一预览导出，像素尺寸按 300 dpi 计算。过长图片超出浏览器画布限制时仍可下载完整 PDF。
- “保存资料”会把当前模板的文字与上传图片下载成 JSON；“导入资料”恢复该文件。新资料版本为 v2，仍支持导入旧 v1 资料：旧介绍和城市迁入 About me，旧补充字段迁入其他，原联系方式与二维码迁入独立组件，旧 UID 显示在头像下方。网页不自动保存，不使用账号、后端服务或统计脚本。
- 文字与图片只传入本机 Web Worker，不上传服务器。首次字体下载从线上实测约 31 MiB 降至约 7.3 MiB（原始两套字体合计约 41.3 MiB），字体与排版引擎并行加载。输入生僻字时按需加载对应完整字库，保留原有字符覆盖和外观。所有资源从当前站点加载，不依赖第三方字体 CDN。
- 字体使用带内容哈希的文件名和本机 Cache Storage 缓存，再次打开可复用；校验失败的缓存自动重新下载，缓存不可用时回退到普通网络加载。缓存仅包含公开字体，不保存个人文字或上传图片。旧浏览器不支持原生解压时沿用完整字体加载。

## 本地开发

需要 Node.js 22.12+。

```sh
cd web
npm ci
npm run dev
```

```sh
BASE_PATH=/astral-express-resumes/ npm run build
npm run preview
```

访问终端显示的地址下 `/astral-express-resumes/`。`npm run build` 自动从仓库原模板复制必要源码、JSON、图片和字体到临时 `public/`，无需维护另一套模板。`public/`、`dist/`、`node_modules/` 不提交。

## GitHub Pages

仓库 Settings → Pages → Build and deployment 选择 **GitHub Actions**。`.github/workflows/pages.yml` 在相关文件推送到 `main` 后构建并发布 `web/dist`，也支持手动运行。

站点地址：<https://mengmengjiang1999.github.io/astral-express-resumes/>。

如果复制到其他仓库，修改工作流中的 `BASE_PATH` 为对应的仓库子路径；用户主页仓库使用 `/`。全部模板、字体、图片和 WASM 路径均基于该目录。

## 实现与验证

`src/compiler-worker.js` 加载原 Typst 源码，映射 JSON 与图片到内存文件系统，生成同一文档的 SVG 和 PDF。浏览器编译器与渲染器锁定为 `0.8.0-rc3`（Typst 0.15.0）。简历通过各自 `config/profile.json` 编辑，扩列条使用已有配置接口。

`src/main.js` 管理每种模板独立的资料、图片与当前生成版本。修改内容立即禁用旧成品下载；只有当前版本成功排版才重新启用。上传仅接受可解码的 PNG / JPG，单张最大 5 MB、当前模板图片合计最大 20 MB。导入资料文件最大 30 MB。

浏览器测试默认通过本机 Google Chrome 运行：

```sh
npm run build
# 测试会自动启动生产预览服务
npm test
```

字体及其许可证位于原模板 `trailblazer-social-strip/assets/fonts/`。本项目为非官方同人创作，素材说明见仓库各模板 README。

## 字体资源维护

`font-assets/` 保存从仓库原字体生成的常用字子集与覆盖清单。使用 `fonttools==4.60.2` 运行 `python3 scripts/subset-fonts.py` 可重新生成：保留字形、字宽、排版特性及可变字重，覆盖 GB2312 常用汉字、拉丁字符、标点、假名和模板默认用字。原始字体与离线 PDF 不变。

普通构建不需要 Python：`prepare:assets` 复制已生成子集，并从原字体生成按需下载的 gzip 完整字库。原字体哈希不匹配时构建会提示重新生成子集。`font-manager.js` 检测实际文字所需字库，包含正文字体不支持、需要宋体回退的生僻字；升级时替换整套字体解析器，避免同名字体子集相互覆盖。

浏览器测试验证首次字体请求量、断网字体缓存复用、生僻字显示与下载失败后重试，并对比使用常用字库和完整字库时同一内容的 PNG 像素一致性。
