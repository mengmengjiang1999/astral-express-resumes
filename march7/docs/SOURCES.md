## 角色与情节

- **S1 / 角色资料**：[HoYoWiki 三月七·存护](https://wiki.hoyolab.com/pc/hsr/entry/7?lang=zh-cn)。核对星穹列车同行身份与护盾能力；[官方角色预告「来，拍照啦！」](https://www.youtube.com/watch?v=72j1zaI2fg0)用于摄影主题；[角色故事资料](https://honkai-star-rail.fandom.com/wiki/March_7th/Lore)用于六相冰凝成的弓矢与护盾；[角色故事·二转录](https://starrail.honeyhunterworld.com/march-7th-character/?lang=CN)明确弓矢由六相冰凝成，因此标题使用通用武器类别「弓矢」，不将「六相冰弓」作为官方专名。未将医疗、机械维修或情报主管列为能力。
- **S2 / 空间站救援**：[Eye of the Storm 任务与对话记录](https://honkai-star-rail.fandom.com/wiki/Eye_of_the_Storm)。剧情明确展示三月七给被锁定的开拓者施加护盾，阿兰腿部受伤，丹恒协同，阿兰提供电梯密钥，姬子接应。改写只写这次护送与撤离，没有声称她修好电梯、独立击退军团或独自救出全站人员。
- **S3 / 贝洛伯格联络**：[In the Dangerous Muddy Swamp 任务对话](https://honkai-star-rail.fandom.com/wiki/In_the_Dangerous_Muddy_Swamp)。三月七向娜塔莎、奥列格转达布洛妮娅即将解除地下城区封锁的消息。采用这一明确的个人行动，避免将击败可可利亚、封印星核或结束寒潮写成个人功绩。「信息交接」是求职表达，不是新增剧情事件。
- **S4 / 习剑机制与分支**：[「初花习剑录」活动资料](https://wiki.biligame.com/sr/%E3%80%8C%E5%88%9D%E8%8A%B1%E4%B9%A0%E5%89%91%E5%BD%95%E3%80%8D)。训练由彦卿、云璃指导，开拓者安排日程；有十五日约战期限，存在多个结局。
- **S5 / 习剑结果**：[官方活动说明转录：Saga of Primaveral Blade: Swordsage Saga](https://honkai-star-rail.fandom.com/wiki/HoYoLAB/Articles/Saga_of_Primaveral_Blade%3A_Swordsage_Saga)、[Way of Primaveral Blade 对话](https://honkai-star-rail.fandom.com/wiki/Way_of_Primaveral_Blade)。本简历采用正面剑斗取胜路线，分支选择仅在编辑说明中记录，不在简历正文中添加模板说明，不把其他同伴奇遇结果合并为同一次成绩，也不声称晋升剑首或成为剑术大师。

- **S6 / 长夜月的记忆命途能力**：[HoYoverse 官方 3.6 版本角色介绍](https://www.hoyoverse.com/en-us/news/159572)确认长夜月为冰属性记忆角色，与三月七被遗忘的过去有关，并介绍忆灵协战、提高我方忆灵暴击伤害与积累 Memoria 的机制；[长夜月中文技能资料](https://starrailstation.com/cn/character/evernight)核对「长夜」「忆质」中文术语及消耗忆质发动冰属性群攻的机制。武器标题采用通用外形称呼「伞」，可参考[官方长夜月角色预告](https://www.youtube.com/watch?v=vh1ipA1aaUQ)，不自拟武器专名。按用户明确设定，将长夜月人格的能力并入三月七的技术栈，不新增未核实的项目成绩或战斗数值。

- **S7 / 翁法罗斯同伴防护**：[「大墓啊，深藏轮回的秘密」剧情对话记录](https://wiki.biligame.com/sr/大墓啊，深藏轮回的秘密)。长夜月明确说明为开拓者与丹恒施以保护，使二人突破封锁时免遭窃忆者挟持；以用户指定的长夜月人格属于三月七的设定计入履历，只记个人防护行为，不把终结铁墓或拯救全世界归为个人成果。
- **S8 / 二相乐园危机情报整理**：[游戏阅读物「三月七也能看懂的公司部门架构小笔记」转录](https://wiki.biligame.com/sr/三月七也能看懂的公司部门架构小笔记)。4.5 版本阅读物明示三月七整理七大部门及其对二相乐园入画的立场，作为后续行动的备查笔记；成果限于完成记录，不声称由她说服董事或赢得投票。
- **S9 / 二相乐园项目的风险与地点**：[「关于他人的痛苦」剧情对话记录](https://wiki.biligame.com/sr/关于他人的痛苦)。二相乐园存亡系于公司决策，各部门对兽蜕武器化与入画方案意见分歧；三月七的记录发生在千星城，因此角色配置记录为「千星城 · 二相乐园危机期间」（按用户要求，简历页面不再显示地点副标题），不将千星城写成二相乐园市内地点。「入画避险」为将乐园收入画中以保全它的简明求职表达。

- **S10 / 巡猎双剑技能**：[三月七巡猎技能数据](https://hsr.gachabase.net/characters/1224/march-7th/release?branch=release&lang=chs&lang=en)核对战技指定「师父」并提升其速度、师父攻击或施放终结技后积累充能，以及强化普攻造成多段虚数伤害；[HoYoWiki 角色入口](https://wiki.hoyolab.com/pc/hsr/entry/2657?lang=zh-cn)供后续编辑查阅。技术栈改写为实际战斗能力，习剑过程仅保留在项目经历中。

- **页尾结语**：采用用户直接指定的「愿此行，终抵群星！」，不将其标注为三月七个人台词或《星间旅行》歌词。

项目正文采用省略主语的简历表述，以队员、导师、地区代表等称谓替代接洽人物姓名；具体人物与协作关系仅在本文件的依据中保留，以便追溯，不新增职责或扩大个人成果。

技术栈、专业能力与岗位名称是基于上述情节的求职语境改写，不是官方岗位或认证；没有虚构成功率、排名、救援人数、任职年月或身份证明。按用户最新要求，不保留 UID 字段。
